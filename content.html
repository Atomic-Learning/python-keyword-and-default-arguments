In Python, parameters with default values become optional when calling the function.

def function_with_defaults(x, y=10): # y is optional with default value 10 return x + y print(function_with_defaults(5)) # y takes the default value of 10 print(function_with_defaults(5, 3)) # y takes the provided value of 3

When defining a parameter list, positional parameters must be specified first, or there will be an error:

def invalid_function(y=10, x): return x + y

Positional and keyword arguments

Positional arguments must come first in the the argument list. These are passed into parameters by their position. Keyword arguments must be specified after positional arguments and are passed in by their parameter name. The order of keyword arguments does not matter.

def quadratic(x, a=1, b=1, c=0): return a * x ** 2 + b * x + c print(quadratic(2)) # uses default a=1, b=1, c=0 print(quadratic(2, c=1)) # uses default a=1, b=1, overrides default c=0 with c=1 # Non-optional arguments can be passed as keyword arguments. Order is unimportant. print(quadratic(b=3, c=4, x=2)) print(quadratic(2, 2, 3, 4)) # overrides all defaults with positional arguments

Formatting Convention for Equals Signs

In Python style conventions, default values in parameter lists and keyword arguments in function calls are typically written with no spaces around =, as in the examples above.
